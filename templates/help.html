Frequently Asked Questions

What is LexAI and how does it work?
LexAI is a Legal Intelligence Platform designed to parse legal documents, generate summaries, and audit sentences for racial, gender, age, or socioeconomic bias. It utilizes a hybrid AI pipeline that defaults to Google Gemini 2.0 API, falling back to local HuggingFace pipelines or local rule-based keyword matchers if API connections are unavailable.
Which file formats are supported?
LexAI fully supports PDF (.pdf), Microsoft Word (.docx), and Plain Text (.txt) documents. Scanned PDFs are processed locally using textual extraction libraries. Ensure documents are not password protected.
How is my document data secured?
Security is our priority. LexAI implements local database isolation per user. In addition, you can toggle **PII Masking** before uploading—this automatically scans and redacts emails, SSNs, credit cards, and phone numbers locally before sending text payloads to external AI engines.
What is the Developer API and how do I use it?
LexAI exposes secure API endpoints (e.g. `/api/v1/analyze`) for programmatic access. You can generate API Bearer keys under **Account Settings -> Developer Tools**. We provide an interactive API Playground there to test endpoints and copy-paste code snippets in cURL, Python, or Javascript.
